# Wealthly — Product Roadmap

## Purpose

Define product sequencing and protect the stability of the core financial ledger.

Roadmap items are product priorities, not permission to implement future work during unrelated tasks.

## Phase 1 — Stability

- Authentication
- API proxy
- Accounts
- Categories
- Transactions
- Goals
- Budgets
- Reports
- Insights
- Dashboard actions
- Settings
- Logout
- User isolation
- Error handling
- Tests

## Phase 2 — Personalization

- Dark/light/system
- Accent palette
- Persist preferences per user

## Phase 3 — Liabilities and protection

- Credit cards
- Loans
- Insurance

## Phase 4 — Data portability

- CSV exports
- Import support if later requested

## Phase 5 — Financial connectivity

- Bank aggregation
- Provider connection management

## Phase 6 — Investments

- Manual stock/ETF holdings
- Portfolio valuation
- Performance
- Broker integration

## Phase 7 — Net worth

- Assets
- Liabilities
- Net worth
- Historical snapshots
- Net-worth chart

## Product rule

Do not let future roadmap work destabilize the core financial ledger.

Do not implement roadmap items merely because an agent notices an opportunity during another task.

If a task conflicts with roadmap sequencing, follow the explicit task and existing architecture; surface scope concerns rather than silently expanding work.
