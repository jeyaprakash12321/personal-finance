# Skill: Wealthly UI

## Existing visual direction

Wealthly uses a clean personal-finance dashboard aesthetic:
- light green/white foundation
- emerald primary accent
- soft cards
- subtle borders/shadows
- responsive layout
- Tailwind CSS
- shadcn/ui where appropriate

Do not redesign existing screens while fixing backend/auth bugs unless requested.

## Product principles

Financial information should be:
- easy to scan
- clearly labeled
- numerically precise
- consistent across pages
- mobile-friendly

Error messages should tell the user what went wrong in normal language.

Loading states should be present for client-side operations.

Destructive actions should require confirmation where appropriate.
